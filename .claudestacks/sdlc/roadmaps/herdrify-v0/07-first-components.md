# Milestone: First components

## Goal

The first components are installable and work in Herdr: code tree, git, GitHub CI, Kubernetes and Grafana. Each one uses only grants it declares, and their use shows any gaps in the Lua API or the widget set.

## Non-goals

A component catalogue or registry. Components needing JavaScript or assets.
